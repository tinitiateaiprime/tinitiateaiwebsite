How this course works

Three Simple Steps per Slide

1

Read the idea

Each slide starts with one sentence "In plain English" and a comparison to everyday life.

2

Run the code

Every slide runs real SQL on a real PostgreSQL database in your browser, and shows you exactly what comes back.

3

See what changed

The database panel colours every new, changed or removed row. Change the yellow boxes or the code: each Run starts clean, so you cannot break anything.
